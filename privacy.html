Ce que nous gardons, et pourquoi

Votre numéro de téléphone Pour vous envoyer un code de connexion par WhatsApp.
Votre nom Le nom que vous voulez afficher dans l'application.
Votre adresse email (en option) Si vous perdez votre numéro de téléphone ou si vous changez d'appareil, cet email vous permettra de vous reconnecter et de récupérer votre compte facilement.
Les infos de votre boutique Vos produits, vos ventes, vos dépenses, vos clients et votre équipe. Nous gardons ces informations pour que vous puissiez les retrouver sur tous vos téléphones en même temps.

Pas de publicité.

Pas de revente de vos données.

Pas de mauvaise surprise.

Alpha, notre assistant intelligent

  1. Quand vous posez une question à Alpha, nous utilisons les chiffres de votre commerce (ventes, stock, dépenses) uniquement pour vous répondre.
  2. Jamais pour la publicité.
  3. Jamais revendus.

Marche sans internet

Patron marche très bien même quand vous n'avez pas internet. Tout ce que vous écrivez (vos ventes, vos stocks, vos calculs) reste caché et protégé dans votre téléphone.

Dès que votre téléphone retrouve internet, l'application remet tout à jour toute seule. Vos données ne quittent jamais votre téléphone sans être totalement protégées.

Vos droits

  1. Vous voyez tout : toutes vos ventes et tout votre argent sont écrits clairement dans l'application. Vous pouvez tout vérifier.
  2. Vous changez tout : vous pouvez changer le nom de votre boutique, vos prix ou vos produits quand vous voulez.
  3. Vous effacez tout : si vous voulez arrêter, vous pouvez supprimer votre compte directement dans l'application (Plus → Paramètres → Supprimer mon compte). Nous effaçons tout, tout de suite et pour toujours, de nos ordinateurs.
